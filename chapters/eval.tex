\subsection{กลยุทธ์และเครื่องมือทดสอบ}

\begin{itemize}[leftmargin=1.8em, itemsep=3pt]
  \item \textbf{Unit Test} --- ทดสอบ Function, Method และ Class แต่ละตัวแยกกัน
  \item \textbf{Integration Test} --- ทดสอบการทำงานร่วมกันของหลาย Component
\end{itemize}

  \midrule

  React Testing Library & ทดสอบ UI ระดับ Component\\
  jsdom                 & จำลองสภาพแวดล้อม Browser\\
  \bottomrule
\end{tabularx}

\subsection{Module หลักที่ผ่านการตรวจสอบ}

\begin{itemize}[leftmargin=1.8em, itemsep=3pt]
  \item \textbf{Auth} --- การยืนยันตัวตนและการควบคุมสิทธิ์ตามบทบาท
  \item \textbf{Clinical} --- Logic แบบสอบถาม OHIP, OHAT และการคำนวณคะแนนวินิจฉัย
  \item \textbf{Upload} --- Pipeline อัปโหลดไฟล์ปลอดภัยพร้อม Quality-Gate Validation
\end{itemize}

\section{Feedback จากการพัฒนา}

กระบวนการพัฒนาได้รับ Feedback โดยตรงจากผู้เชี่ยวชาญที่มีประสบการณ์จริง
ในการพัฒนาแพลตฟอร์ม Web ทางคลินิกทันตกรรม
ข้อมูลนี้ชี้นำการออกแบบ Interface, Clinical Workflow Integration
และ Logic ของแบบสอบถาม เพื่อให้แพลตฟอร์มสะท้อนความต้องการในการปฏิบัติงานจริง
